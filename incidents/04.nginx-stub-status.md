## Симптом (что произошло)
Алерт в Grafana показывает, что Nginx упал nginx_up = 0. Nginx работает в штатном режиме и отдает запросы.

## Предмет проверки и порядок действий
1. `docker ps -a` — Nginx в статусе UP
2. Postman: http://localhost/users — код 200
3. Браузер Windows: http://localhost/users — запрос прошел и выдал таблицу users
4. `docker logs nginx` — строка `GET /basic_status HTTP/1.1" 404 125 "-" "NGINX-Prometheus-Exporter/v0.0.0-SNAPSHOT-bae43bc` — запрос идет от экспортера, а не от пользователя.
5. `cat default.conf` — увидел изменённую строку `location = /basic_status_old`

## Что не подтвердилось
Падение nginx не подтвердилось. Экспортер не сломан, prometheus запрашивал статистику у экспортера и он каждые 15 секунд запрашивал у Nginx /basic_status, после правки конфига запрос снова получил код 200.

## Причина инцидента
Prometheus обращается к экспортеру каждые 15 секунд, и экспортер обращается к /basic_status, получает 404 и отдает nginx_up = 0

В конфиге default.conf был переименован путь.

Должно быть:

```
location = /basic_status {
    stub_status;
}
```

Вместо:

```
location = /basic_status_old {
    stub_status;
}
```

Лишние символы "_old" — экспортер получал 404 и алерт оповещал о падении nginx.

Кто переименовал путь — неизвестно.

## Как устранил инцидент
Через nano default.conf и перезапустил nginx через `docker restart nginx`.

В логе nginx стало как и было ранее `GET /basic_status HTTP/1.1" 200 97 "-" "NGINX-Prometheus-Exporter/v0.0.0-SNAPSHOT-bae43bc`

Алерт вернулся в Normal.

## Как избежать инцидент в будущем
Вести отчет по правкам конфига (кто и когда это делал)
