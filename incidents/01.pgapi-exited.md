## Симптом (что произошло)
PostgREST (pgapi) не отвечает. GET /users отдает ошибку в Postman

## Предмет проверки и порядок действий
1. docker ps — увидел, что в запущенных процессах нет postgrest (pgapi)
2. docker ps -a — pgapi было завершено в статусе Exited (0).
3. journalctl -u docker.service

## Что не подтвердилось
Не проверялось отдельно — причина нашлась сразу через docker ps -a

## Причина инцидента
Контейнер pgapi был остановлен, статус Exited (0). Подтвердил через journalctl -u docker.service: поле hasBeenManuallyStopped=true показывает, что остановка была инициирована вручную

## Как устранил инцидент
docker start pgapi, проверка через Postman и браузер Windows. 

## Как избежать инцидент в будущем
Ввести алерт с оповещением для pgapi, чтобы узнавать о падении своевременно, а не по жалобе из Postman
