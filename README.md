# support-practice
## О проекте
Учебный стенд на моём ноутбуке, самообучение после прохождения курса Инженер сопровождение L2. 

## Из чего состоит стенд 
- VirtualBox, Ubuntu Server 24.04
- Docker — запускает каждую программу стенда в изолированном контейнере
- Nginx — веб-сервер, принимает запросы на порт 80 и передаёт их в PostgREST (обратный прокси)
- PostgREST — веб-сервер, который автоматически превращает любую базу данных PostgreSQL в готовый RESTful API
- PostgreSQL — база данных с таблицами users, orders, products. Выполняются запросы на языке SQL 
- Prometheus — cистема для мониторинга серверов и приложений
- Grafana — cистема для визуализации и анализа мониторинга данных 
- Экспортеры — переводят показатели сервера и Nginx в формат, который понимает Prometheus (сам Nginx и виртуалка в этом формате ничего не отдают)

## Инструменты для работы со стендом
- Postman (десктоп) — отправка запросов к PostgREST, разбор ответов и заголовков
- DBeaver — подключение к базе PostgreSQL через SSH-туннель, SQL-запросы


## Как идет запрос
- запрос → Nginx (порт 80) → PostgREST (порт 3000) → PostgreSQL (порт 5432)

## Инциденты
Разборы лежат в папке incidents.
