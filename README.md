# support-practice
## О проекте
Учебный стенд на моём ноутбуке, самообучение после прохождения курса Инженер сопровождения L2. 

## Из чего состоит стенд 
- VirtualBox, Ubuntu Server 24.04
- Docker — запускает каждую программу стенда в изолированном контейнере
- Nginx — веб-сервер, принимает запросы на порт 80 и передаёт их в PostgREST (обратный прокси)
- PostgREST — веб-сервер, который автоматически превращает любую базу данных PostgreSQL в готовый RESTful API
- PostgreSQL — база данных с таблицами users, orders, products. Выполняются запросы на языке SQL 
- Prometheus — система для мониторинга серверов и приложений
- Grafana — система для визуализации и анализа мониторинга данных. Есть алерт на nginx_up, срабатывает, когда Nginx перестает отвечать экспортеру
- Экспортеры — переводят показатели сервера и Nginx в формат, который понимает Prometheus (сам Nginx и виртуалка в этом формате ничего не отдают)

Контейнеры Nginx (nginx), PostgreSQL (pg), PostgREST (pgapi), Prometheus (prometheus), Grafana (grafana), NGINX Prometheus (nginx_exp) подключены к пользовательской сети my-net и обращаются друг к другу по имени.

Node Exporter не подключен к этой сети, так как работает в сети хоста и собирает метрики самого сервера.

### Карта портов сервисов

| Сервис | Внутренний порт | Внешний порт (Host/Windows) | Описание / Назначение |
| :--- | :---: | :---: | :--- |
| **Nginx** | `80` | `80` | Входной веб-сервер и обратный прокси |
| **PostgREST** | `3000` | `3000` | Автоматическое REST API для СУБД |
| **Grafana** | `3000` | `3002` | Визуализация метрик и дашборды |
| **PostgreSQL** | `5432` | `5432` | Основная база данных |
| **Prometheus** | `9090` | `9090` | Сервер сбора и хранения метрик |
| **Экспортёр Nginx** | `9113` | `9113` | Трансляция метрик Nginx в Prometheus |





## Инструменты для работы со стендом
- Postman (десктоп) — отправка запросов к PostgREST, разбор ответов и заголовков
- DBeaver — подключение к базе PostgreSQL через SSH-туннель, SQL-запросы


## Как идет запрос
- запрос → Nginx (порт 80) → PostgREST (порт 3000) → PostgreSQL (порт 5432)

## Инциденты
Разборы лежат в папке incidents.
Скрипт со случайным выбором поломки стенда. Диагностика идет без подсказок. Причина поломки заранее неизвестна, по этой причине в разборах встречатся "неизвестно".
